Rev-B instantiates a default-off MCU–FPGA SPI bridge on `kestrel_pcb/rev-b/electrical/kestrel-revb-spi.kicad_sch`, generated by `tools/build_spi.py` after MCU support and before `build_project.py`. This is a connectivity-reviewed engineering draft; system sequencing, firmware and timing remain unqualified. It leaves FPGA-master, converter-slave audio clocks unchanged.

U801 SN74AXC4T774PWR uses the PW16 TSSOP package and `Package_SO:TSSOP-16_4.4x5mm_P0.65mm`. Main +3V3_D supplies VCCA16; switched +3V3_FPGA supplies VCCB15. GND10 and DIR4 pin8 ground; DIR1/2/3 pins1/2/7 tie to main supply. A1/2/3 pins3/4/5 receive MCU GPIO4 CS, GPIO5 clock and GPIO6 MOSI. B1/2/3 pins14/13/12 drive FPGA49/55/48 through R801–803 33-ohm damping footprints. FPGA51 MISO drives B4 pin11; A4 pin6 returns through R804 33 ohms to MCU GPIO14 physical15. Separate MCU_RAW_* and FPGA MCU_SPI_* nets are essential to retaining physical domain separation. Four local 100-nF bypasses serve both translator supplies, supervisor and NAND. C801/C802 use selected 0402 Samsung parts; C803/C804 remain 0603.

TI Rev C Table4-1 independently defines this PW pin map; DIR high selects A-to-B and low B-to-A. OE9 high disables outputs. The specified Ioff and either-VCC-below-100-mV isolation address partial power down, not arbitrary intermediate system voltage behavior. Internal typical 71k I/O pulldowns mean external pullups must be no larger than 7k per §7.3.9: R805 and R806 are 4.7k CS pullups to their own receiving/input domains. Clock and MOSI retain internal pulldowns. Guaranteed pullup margin including FPGA/MCU loads requires qualification. [TI SN74AXC4T774](https://www.ti.com/lit/ds/symlink/sn74axc4t774.pdf).

U802 TPS3808G01DBVR is main-powered: pin6 VDD, pin2 ground, pin5 SENSE via R810 63.4k/0.1% from switched FPGA power and R811 10k/0.1% to ground, with C805 1nF C0G filtering. Pin3 MR receives MCU reset103; CT4 is intentionally open. Pin1 open-drain RESET_N, named SPI_RAIL_RELEASE, has R809 10k pullup to main power. Nominal falling threshold is 2.9727V; using Rev N ±2% threshold, ±25nA sense current and resistor limits gives 2.90663–3.03898V. CT-open release delay is specified 12–28ms under TI test conditions; filter settling/hysteresis and full-system timing are additional. This is a shutdown isolation guard, deliberately below the FPGA 3.135V minimum. A released supervisor does not certify a valid FPGA rail or configured FPGA. [TI TPS3808](https://www.ti.com/lit/ds/symlink/tps3808.pdf).

U803 SN74LVC1G00DCKR NAND uses DCK5 pin1 MCU_SPI_ENABLE, pin2 SPI_RAIL_RELEASE, pin3 ground, pin4 SPI_OE_N and pin5 main supply. MCU GPIO7 physical7 supplies enable with R808 10k pulldown. R807 10k pulls OE high. At valid main supply, OE_N = NOT(enable AND rail_release), giving default-off operation until both inputs are high; MCU reset forces supervisor reset and restarts release delay. NAND pin map follows TI's DCK table; operation during underspecified ramps remains to test. [TI SN74LVC1G00](https://www.ti.com/lit/ds/symlink/sn74lvc1g00.pdf).

Firmware must initialize enable low, set CS high/clock low before enabling, await rail settling and FPGA configuration, then assert GPIO7; disable it before controlled shutdown/reconfiguration. This contract is not implemented in current firmware. The existing 10MHz mode0 SPI has a 50ns half-cycle; translator specifications at 3.3±0.3V give 5ns maximum propagation per direction under TI loading, but FPGA CDC/clock-to-output, MCU setup, damping and PCB loads must be included before claiming timing closure.

`tools/propose_signal_route.py` is a read-only bounded candidate search, run with the KiCad MCP Python venv containing pcbnew, NumPy and Shapely. It accepts `--board`, `--start REF.PAD`, `--end REF.PAD`, reviewed `--bounds XMIN YMIN XMAX YMAX` and `--output JSON`; it never saves a board. It models the current four-layer board with one In1.Cu ground zone, conservative pad bounding boxes, tracks and through-via annuli, using pad/footprint local clearance where present and otherwise 0.2 mm, plus 0.01 mm search margin. Candidate traces are 0.127 mm and vias 0.5/0.3 mm. Proposed vias keep at least 0.2 mm annulus clearance from every pad land, including same-net pads, plus search margin. A 0.05-mm raster searches F.Cu/In2.Cu/B.Cu with a via penalty; aligning its origin to fine-pitch pad coordinates prevents avoidable grid escapes, and routing order must preserve adjacent-pin corridors. It does not model board edges, keepouts, custom rules, impedance or return current. Review bounds and geometry, test each candidate in native DRC with the matching project profile, then add accepted copper through guarded manifests/builders and verify endpoint continuity. Copper-clear candidates can still require electrical revision.
