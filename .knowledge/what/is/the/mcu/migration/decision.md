Rev-B keeps ESP32-P4 as the engineering target; use ESP32-P4NRW16X (16-MB in-package PSRAM, revision v3.x), with NRW32X an option if memory requirements justify it. STM32H743 migration is not justified by the present control/UI workload: FPGA owns audio DSP, while the Interface already depends on ESP-IDF SPI/DMA, GPIO/interrupts, FreeRTOS, LCD, LDO and USB services. Portable LVGL/application code can be reused, but an H743 requires replacement board drivers, startup/build/configuration and hardware testing. No migration duration or comparative benchmark has been established.

At 800×480 RGB565 a framebuffer is 768,000 bytes; two require 1,536,000 bytes. ST's STM32H743 datasheet specifies 512-KiB AXI SRAM plus separate SRAM/TCM banks. A conventional contiguous full-color framebuffer exceeds that AXI allocation and double buffering exceeds total internal RAM. External display memory is the straightforward H743 implementation; palette/partial-buffer approaches require a separately validated rendering architecture. P4 in-package PSRAM avoids an external SDRAM interface. This is an engineering inference from memory capacity, not a measured display test. Source: https://www.st.com/resource/en/datasheet/stm32h743vi.pdf, sections 3.3.2 and LTDC.

Retaining P4 still requires replacing the existing Waveshare HX8394 MIPI board/display dependencies with the chosen RGB/I2C panel driver, removing SGTL5000 initialization, assigning Rev-B GPIOs and proving the build on actual silicon. Evidence: kestrel_interface/main/idf_component.yml, main/kest_int.h, components/fpga/kest_fpga_io.c and sdkconfig. Current SPI uses GPIO14 MISO, GPIO6 MOSI, GPIO5 clock and GPIO4 CS; these are compatibility candidates, not a final board pin allocation.

Espressif PCN202600801 recommends NRW16X/NRW32X and plans EOL for the earlier NRW16/NRW32. Revision v3.2 adds HP supply pin 54 and requires the populated HP DC/DC feedback network, ESP-IDF v5.5.3+ or v6.0+ and ESP32P4_SELECTS_REV_LESS_V3=n. Old and new revisions cannot share one binary. Source: https://documentation.espressif.com/PCN202600801_ESP32-P4_Chip_Revision_v3.2_Upgrade_Chip_Revision_v1.3_Demand_Collection_and_EOL_Plan_Description.pdf.
